# 数据库结构还原规则

## SQL 与版本

- 递归盘点主 SQL 目录中的 `.sql` 文件，大小写扩展名均纳入；沿脚本引用继续查找外部 SQL、模板及生成器。二进制备份和无法读取的文件单列，不视为已分析。
- 用安装脚本、迁移框架版本记录、include/source/\i 引用和部署配置判断加载顺序。按真实引用语义解析相对路径；记录条件分支、参数和适用数据库。历史全量快照、测试夹具、不同方言和互斥版本分别归类。
- 保留原始类型及精度、长度、数组/枚举/域、NULL、默认表达式、identity/auto increment/序列、生成列、排序规则、注释和列级约束。数据库默认行为与显式 DDL 分开标识。
- 补齐表级主键、复合唯一键、外键及更新删除规则、CHECK、排除约束、引擎、字符集、表空间、存储参数、继承及分区。无主键如实记录，不补造。
- 索引逐项保留名称、所属表、类型/方法、列或表达式及顺序、ASC/DESC、唯一性、过滤谓词、INCLUDE/覆盖列、前缀长度、操作符类、有效/启用条件等适用属性。区分显式索引和数据库隐式创建的约束索引，统计口径避免重复。
- 视图保留输出列、完整定义或可定位的原定义、基础表/视图依赖、过滤聚合关联逻辑、可更新性依据；物化视图另述刷新触发、方式及索引。仅凭出现 SELECT 不推断可更新性。
- 函数/过程记录签名、返回值、职责、读写对象、调用与异常；触发器记录事件、时机、粒度、条件和动作；序列记录起点、步长、边界、循环、缓存及归属。权限、任务和扩展记录实际定义及依赖。

## 源码与分表追踪

按“建表定义/模板 → 创建调用 → 表名计算/路由 → 读写调用 → 清理归档任务”追踪完整链路；任一环缺失均标明。SQL 不存在但源码明确生成的对象按运行时模板记录，不能虚构已创建的实例列表。

| 维度 | 必须查明的内容 |
| --- | --- |
| 类型与归属 | 分库、应用分表或原生分区，逻辑表、物理表/模板及组件 |
| 路由 | 键来源、hash/mod/范围算法、桶数、映射配置、空值和非法值处理 |
| 时间边界 | 时间字段、业务/入库时间、粒度、时区、区间开闭、跨期及迟到数据 |
| 创建 | 启动/定时/按需创建、预建窗口、并发幂等、DDL 和索引来源 |
| 查询 | 单表路由、跨片合并、分页排序、统计、事务与唯一性范围 |
| 生命周期 | 保留期限、删除/归档触发、清理范围、依赖处理、故障及补偿 |
| 变更 | 新字段/索引怎样同步已有与未来分表，迁移或扩容机制 |

原生分区另保留分区键/表达式、策略、每个边界与默认分区、子分区、attach/detach 和维护动作。容量、热点、索引有效性和备份恢复只能描述材料支持的设计；建议单列。

## 证据和覆盖记录

中间清单可用 Markdown 表格或结构化文件，至少保留：对象标识、类型、最终状态、定义来源、变更链、源码语义来源、文档位置、疑问。引用使用项目相对路径与可核对的行号/符号；不依赖只在作者机器有效的绝对路径。大对象可在附录放关键 DDL 或相对链接，字段字典和设计说明仍需在正文完整展开。

分别统计“扫描发现”“纳入基线”“当前有效”“已描述”“待确认”；模板与实例分别计数，物理外键与逻辑关系分别计数。对无法完成的解析明确范围及影响，禁止用一次 CREATE TABLE 正则匹配结果证明全量覆盖。
