# 快捷按钮扩展设置与原生 PI 设置分离

三轮需求讨论已确认：Matt Skill 按钮作为可编辑预置，全部 Skill 按钮由统一的全局用户配置驱动。快捷按钮页面、配置存储、校验及迁移集中在扩展模块，配置独立于原生 PI 设置，原生设置导航与 Composer 仅保留必要接入点。

将配置继续放入原生设置结构虽可复用现有读写，但会扩大同步上游时的修改与迁移范围。独立存储以带版本的配置承接旧提示词，保留用户改动和可恢复备份；代价是维护独立的持久化与兼容逻辑，并仍需验证导航和 Composer 接口兼容。

本决策用于降低上游升级耦合。应用继续统一打包发布，首版只迁移快捷按钮及原有提示词设置，其他扩展设置保持当前行为。用户于 2026-10-06 确认整体需求，本决策已接受；当前没有实现该边界。
