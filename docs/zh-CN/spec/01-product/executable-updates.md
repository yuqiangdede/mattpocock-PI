# 显式更新应用与工程技能

> **翻译说明：** 本页对应 [英文源规格](/spec/01-product/executable-updates)。代码、协议字段和标识符保持原文。

设置提供 Matt Pocock 技能和 mattpocock-PI 两个更新来源。上游 PI-Desktop 版本不是可独立安装的来源；应用版本只包含维护者已经合并的上游改动。

检查不会下载或安装，每个来源有独立的更新操作。应用支持 stable 和 prerelease 通道，预览版默认使用 prerelease。只有严格更新的语义版本才能更新。切换通道会清除旧检查和下载状态，并保存所选通道。

Windows 安装版使用 fork 固定的 electron-updater 更新源。下载由用户发起，并验证更新源校验值；正常退出不会安装。运行任务结束后，用户明确选择“重启并更新”。Portable/ZIP 下载匹配的发布文件到应用配置目录缓存，验证公开校验值后显示文件，供用户手动替换；不会执行 NSIS 安装器。开发版不能安装更新。错误保持可见且可重试，未完成的下载不会显示给用户。

技能更新复用不可变版本下载和 Host 验证。Host 在配置目录中备份已安装目录，再原子切换到新目录；失败时当前目录保持不变。“恢复上次备份”由用户明确发起，保留后续本地修改并原子切换。全局和项目用户技能不会被修改。本地修改或删除的内置技能会保留并列出；未修改且被上游移除的技能退出当前目录，文件保留以供恢复。

任何任务运行时都禁止更新或恢复技能，包括下载期间新启动的任务；界面说明阻止原因。

验证使用模拟更新源与隔离配置目录，不调用真实模型或用户正在运行的应用。场景见交付 E2E 测试计划。
