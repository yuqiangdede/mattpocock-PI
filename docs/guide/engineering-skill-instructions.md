# Engineering skill instructions

Hover over a skill button in the Composer, or focus it with the keyboard,
to see when to use it, its purpose and an example. This also works for
skills in the requirements menu and More. Reading guidance does not
modify the draft; click the button only when you want to insert its skill.

Open **Settings > Agent > Skills > Engineering shortcut instructions** and
select an entry. All 26 engineering entries, including Ask and More menu
skills, have guidance explaining when to use them, what they do, and an
example request. English and Simplified Chinese have dedicated copy;
other interface languages use the English guidance.

Read the guidance above the default instruction editor, then edit the
instruction and choose **Save instruction** if needed. Guidance and examples
are read-only and are not inserted into the Composer. Saving an empty
instruction inserts only the skill marker; **Restore default** returns to
the built-in instruction for the current language.

Instructions apply across projects. Skill updates preserve custom
instructions. Changes affect future shortcut selections, leaving existing
drafts intact. Selecting a shortcut prepares a draft; use Send explicitly
to execute it.
